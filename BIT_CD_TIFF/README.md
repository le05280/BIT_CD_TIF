​​BIT-CD: 基于Transformer的遥感图像变化检测模型​​

BIT-CD（Remote Sensing Image Change Detection with Transformers）是一种基于Transformer架构的遥感图像变化检测模型，旨在高效识别双时相遥感图像中的地表变化区域。该模型通过融合全局上下文信息，显著提升了建筑物、植被等地物变化的检测精度，特别适用于大范围复杂场景的变化分析。

原文链接🔗：https://ieeexplore.ieee.org/document/9491802

本文对该模型的输入进行了修改，实现多特征TIF的输入，相较于原始的三波段RGB有了明显的提升。
